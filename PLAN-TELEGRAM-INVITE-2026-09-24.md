# План: приглашение в Telegram для родителей и учеников — 2026-09-24

## Проблема
Родителя заводит администратор (`ParentsService.createForStudent`): логин
генерируется, пароль случайный и никому не известен. Задумано, что родитель
входит через Telegram, но войти через Telegram может только тот, у кого
Telegram уже привязан, а привязать его можно только из профиля — то есть уже
войдя. Замкнутый круг. На проде 2026-09-24: 74 ученика, ни у одного Telegram не
привязан; родителей пока нет. Уведомления родителям (пропуски, оценки,
сводка) уходят только тем, у кого привязан Telegram.

## Что уже есть (переиспользовать, не дублировать)
- `TelegramLinkRequest` (code unique, userId, expiresAt) и
  `api/src/modules/users/telegram-link.service.ts` → `createCode(userId)`
  (сейчас TTL 15 минут, прошлые коды пользователя удаляет).
- Бот: `/start <код>` → `handleLinkAccount` в
  `api/src/modules/notifications/telegram-bot.service.ts` привязывает chat id к
  пользователю и удаляет код. Имя бота: `TELEGRAM_BOT_USERNAME` (api отдаёт его
  на `GET /auth/telegram/bot`).
- После привязки вход на сайт — кнопкой «Войти через Telegram» на странице
  входа (`telegram/request` → подтверждение в боте). Пароль не нужен.
- SMS: `SmsService.sendOne({ phone, text, userId })`
  (`api/src/modules/notifications/sms.service.ts`), пишет `SmsLog`.
- Блок родителей в карточке ученика: `src/components/parents-panel.tsx` на
  `src/app/[locale]/(dashboard)/users/[userId]/edit/page.tsx`.

## Что сделать

### 1. API
- `POST /users/:id/telegram-invite` (только администратор,
  `ability.can("manage", "User")`): для пользователя-родителя или ученика
  создаёт код приглашения и возвращает `{ url, expiresAt, isLinked }`, где
  `url = https://t.me/<бот>?start=<код>`. Код приглашения живёт **7 дней**
  (а не 15 минут, как код из профиля): его отправляют по SMS, и человек может
  открыть его не сразу. Сделай TTL параметром `createCode(userId, ttlMs)` —
  код из профиля остаётся 15 минут. Новый код заменяет прежние коды этого
  пользователя (как сейчас). Если Telegram уже привязан — всё равно можно
  выдать (переприкрепить к новому телефону), но `isLinked: true` в ответе.
  Бот не настроен (`TELEGRAM_BOT_USERNAME` пуст) — 409 с понятным кодом.
- `POST /users/:id/telegram-invite/sms` — то же + отправка SMS на
  `User.phone` через `SmsService.sendOne` (userId для журнала SMS). Текст —
  на узбекском, коротко: «Best Direction: {Имя}, bildirishnomalar va kirish
  uchun Telegram'ni ulang: {url}» (подбери формулировку ≤ 2 SMS-частей;
  `countSmsParts` есть в сервисе). Ответ: отправлено / причина
  (`notConfigured`, `invalidPhone` и т.п. — сервис их уже возвращает). Нет
  телефона — 400 с кодом.
- Журнал действий (`audit.record`): кто кому выдал приглашение и каким
  способом.
- Тесты `api/test/telegram-invite.e2e-spec.ts`: только администратор;
  ссылка содержит код, код живёт 7 дней; повторная выдача отменяет прежний;
  после `/start <код>` (вызови `handleLinkAccount` так, как это делают
  существующие тесты бота, или напрямую через сервис) — привязка есть;
  SMS — sendOne вызван с телефоном пользователя (замокай).

### 2. Web
- В `parents-panel.tsx` у каждого родителя — кнопка «Пригласить в Telegram»;
  статус «Telegram привязан ✓ / не привязан» (поле `telegramChatId` уже
  есть в ответе? если нет — добавь в выдачу родителей признак `hasTelegram`,
  сам chat id наружу не отдавать).
- Та же кнопка в карточке ученика (для самого ученика) — на странице
  `users/[userId]/edit` рядом с его данными, если роль STUDENT или PARENT.
- Диалог приглашения: ссылка + кнопка «Скопировать», **QR-код** ссылки
  (пакет `qrcode` для web: добавь в КОРНЕВОЙ `package.json` только его —
  проверь, что не тянется ничего лишнего; рисовать на клиенте в `<canvas>`
  или SVG), кнопка «Отправить по SMS» (показывает номер, на который уйдёт),
  срок действия ссылки. Короткая инструкция для администратора: «Родитель
  открывает ссылку, нажимает Start в боте — после этого получает уведомления
  и входит на сайт кнопкой „Войти через Telegram“».
- Переводы ru/uz (латиница), без переформатирования JSON.
- Телефон: диалог нормально выглядит на 360px.

### 3. Страница входа
Проверь, что на странице входа кнопка «Войти через Telegram» заметна и
подписана понятно для человека без пароля (например, «Parolingiz yo'qmi?
Telegram orqali kiring»). Если её там нет или она спрятана — сделай
заметной. Ничего в логике входа не менять.

## Не делаем сейчас
- Массовая рассылка приглашений всем без Telegram (можно следующим шагом:
  кнопка на странице пользователей).
- Язык пользователя (всё на узбекском, как остальные сообщения бота).

## Риск, о котором сказать владельцу
SMS через Eskiz: для текстов со ссылками шлюз может требовать заранее
одобренный шаблон. Если отправка вернёт ошибку модерации — это настройка в
кабинете Eskiz, не баг. Отметить в отчёте, если в коде/доках Eskiz есть
признаки этого.
