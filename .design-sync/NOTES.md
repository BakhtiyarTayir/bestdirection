# design-sync notes — lms (uPortal LMS)

- App repo, not a packaged DS: no `dist/`, no build for a component package. Converter runs in synth-entry mode over `srcDir: src/components/ui` (26 shadcn/ui components). `cfg.entry` deliberately points at nonexistent `./dist/index.js` — that anchors PKG_DIR at the repo root and drops the converter into synth mode; the `[NO_DIST]` warn on every build is expected.
- Components import `cn` from `@/lib/utils` — `tsconfig` is set so esbuild resolves the `@/` alias. `tsconfig.json` `exclude` lists `.design-sync`, `.ds-sync`, `ds-bundle` so the app's typecheck ignores preview files (they import from 'lms', which only resolves at preview-compile time).
- Tailwind v4, CSS-based config. `cssEntry` = `.design-sync/.cache/tailwind-compiled.css`, regenerated by `buildCmd` from the committed wrapper `.design-sync/tw-entry.css` (imports `src/app/globals.css` and defines `--font-geist-sans`/`--font-geist-mono`, which next/font injects at runtime in the real app). Tailwind auto-scans repo sources incl. `.design-sync/previews/` — re-run `buildCmd` + full `package-build.mjs` after authoring previews with new classes (arbitrary values like `w-[360px]` only exist after a scan).
- Fonts: Geist/GeistMono variable woff2 committed under `.design-sync/fonts/` (copied from the `geist` npm package, SIL OFL) + `geist.css` with `@font-face`; wired via `extraFonts`. The `:root` var block in that file does NOT survive extraction (only `@font-face` is harvested) — the vars live in `tw-entry.css` instead.
- Render checks: no playwright cache — system Chrome is used via `DS_CHROMIUM_PATH=/usr/bin/google-chrome` for both `package-validate.mjs` and `package-capture.mjs`. Playwright (no browsers) is installed in `.ds-sync/`.
- Card list curated to 26 file-level primaries; 79 compound subparts excluded via `componentSrcMap: null` (they stay exported on `window.LMS` and appear in parent previews). `overrides.<Name>.skip` is a per-story ARRAY, not a boolean.
- `overrides.Select = {cardMode: "single", primaryStory: "Open"}` — Radix portal content positions fixed and escapes grid cells; expect the same for other overlay components (Dialog, AlertDialog, DropdownMenu, Popover, Tooltip, Toast).
- Preview content style: Russian, LMS-themed (курсы, группы, уроки, домашние задания). lucide-react imports in previews bundle fine.

## Preview-authoring lessons (folded from wave learnings)

- `preview-rebuild` does NOT rerun Tailwind — only classes already in the compiled CSS resolve. For sizes use inline `style={{width: N}}`; missing utilities encountered: `max-w-sm`, `my-2/4`, `grid-cols-3`, `-space-x-*`, `border-background`, `w-fit`, `tabular-nums`.
- Overlays (Dialog/AlertDialog/DropdownMenu/Popover) render open with plain `defaultOpen` inside a container with inline height 260–460px; nothing escaped grid cells, no cardMode overrides needed (only Select needed `single`).
- Tooltip needs `<TooltipProvider>` per story; `defaultOpen` works statically.
- Toast: `ToastViewport className="static p-0"` keeps toasts in-flow (tailwind-merge lets `static` beat `fixed`); `duration={100000}` guards against auto-dismiss racing capture.
- ScrollArea must pass `type="always"` or scrollbars are invisible in static screenshots.
- Calendar root isn't `position:relative` while its nav arrows are absolute — previews add `className="relative"`. Possible app-side bug (arrows anchor to nearest positioned ancestor).
- DatePicker calls `useTranslations("datePicker")` → needs same-instance NextIntlClientProvider. Solved via `extraEntries: ["./.design-sync/ds-provider.tsx"]` exporting `DsIntlProvider` (ru messages, Asia/Tashkent); the DatePicker preview wraps itself in it. Other i18n-dependent components can do the same.
- APP BUG FIXED during sync: `globals.css` had unlayered `* { @apply border-border; }` which beat every border-color utility (`border-destructive`, `border-primary` never applied — in the real app too). Wrapped in `@layer base` (2026-07-10).
- Avatar offline-safe images: inline SVG data URI through AvatarImage works.

- 2026-07-10 rebrand: theme tokens switched to IT School brand (primary #8C120C red, warning #F6B93B amber, ink foreground #191211) — source of truth is «IT School - Brend Kit/» at repo root. Brand kit prescribes Space Grotesk/Manrope fonts; NOT adopted (app still ships Geist) — if fonts change later, update `.design-sync/fonts/` + `tw-entry.css` + conventions.md.

## Re-sync risks

- `.design-sync/.cache/tailwind-compiled.css` is generated state — a re-sync MUST run `buildCmd` first or the converter copies a stale stylesheet.
- Geist woff2 files are pinned copies from `geist@1.x` — if the app's font changes (layout.tsx `next/font` imports), update `.design-sync/fonts/` and `tw-entry.css` to match.
- The compiled Tailwind CSS depends on class usage across the whole repo; deleting app pages can silently drop utilities that previews rely on. Validate + contact sheets will catch it.
